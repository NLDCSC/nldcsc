# NLDCSC documentation

NLDCSC is a collection of reusable Python modules for application infrastructure,
integrations, and development tooling. It is not a single deployable service:
install the extras needed by an application and import the modules directly.

## Contents

- [Usage](usage/index.md) — installation, optional extras, and common integration patterns.
- [Configuration](configuration/index.md) — package extras and supported runtime settings.
- [Development](development/index.md) — repository layout, contribution workflow, and local setup.
- [Testing](development/testing.md) — unit tests, coverage, formatting, and documentation checks.
- [Module reference](reference/index.md) — map of the complete `nldcsc` source package.
